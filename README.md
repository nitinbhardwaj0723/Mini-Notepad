# Mini Notepad 📝

Mini Notepad is a simple text editor application developed using **C# Windows Forms (.NET Framework)**. It provides basic text editing features with an easy-to-use interface.

## Features

- **New:** Create a new blank document.
- **Open:** Open existing `.txt` files.
- **Save:** Save text into `.txt` files.
- **Exit:** Close the application.
- **Cut:** Remove selected text.
- **Copy:** Copy selected text.
- **Paste:** Paste copied text.
- **Word Count:** Displays the total number of words.
- **Character Count:** Displays the total number of characters.

## Technologies Used

- C#
- Windows Forms
- .NET Framework
- Visual Studio
